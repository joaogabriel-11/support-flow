# Estratégia de Testes

## Testes unitários

Utilizados para:

- validação das transições de status;
- regras de prioridade;
- validação de permissões;
- bloqueio de desativação de agentes.

## Testes de integração

Utilizados para:

- criação de chamados;
- atribuição de agentes;
- gravação do histórico;
- comentários e alteração automática de status.

## Testes E2E

Fluxos principais:

- solicitante abre chamado;
- agente assume e resolve;
- solicitante confirma a resolução;
- admin cria e desativa usuários.
